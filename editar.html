Editar

Gestiona quién se ha pasado cada nivel. Para añadir niveles nuevos usa el panel de niveles.

Conecta la página con tu GitHub una sola vez. Así los cambios se guardan directamente en la web, sin usar GitHub Desktop.

  1. Abre la página para crear un token (o ve a Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token).
  2. En Token name pon lo que quieras, por ejemplo «Maguiet Server List». En Expiration elige el máximo.
  3. En Repository access elige Only select repositories y marca Maguiet-Server-List.
  4. En Permissions → Repository permissions, busca Contents y ponlo en Read and write.
  5. Pulsa Generate token, copia el código (empieza por github_pat_) y pégalo aquí abajo.

El token se guarda solo en este navegador. No se lo des a nadie.

Orden de llegada: el primero en pasárselo va arriba. Puedes corregir nombres y fechas directamente.
