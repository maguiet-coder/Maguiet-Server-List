¿Cómo consigo el token?
  1. En github.com pulsa tu foto de perfil, Settings y, abajo del todo, Developer settings.
  2. Personal access tokens → Fine-grained tokens → Generate new token.
  3. En Repository access elige Only select repositories y marca Maguiet-Server-List.
  4. En Permissions → Repository permissions pon Contents: Read and write.
  5. Pulsa Generate token, copia el código y pégalo aquí.

¿Prefieres no usar el token? Usa el generador de código y pega el resultado en niveles.js.
